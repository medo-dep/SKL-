# Raw to Reel ✳ — مونتاج الفيديو بضغطة واحدة

نسخة مجانية من الأداة اللي في الريل: صفحة تفتح في كروم، تختار الفيديو الخام، تفعّل التعديلات، وتضغط زر واحد، فتطلع لك ريل جاهز (1080×1920) مع Timeline لـ DaVinci Resolve.

## التشغيل

```bash
# مرة واحدة فقط
brew install ffmpeg            # ماك  (ويندوز: winget install ffmpeg)
pip install faster-whisper     # للترجمة وحذف الكلمات الزائدة والإعادات
pip install opencv-python-headless   # لتتبّع الوجه وتوسيط الشخص

# كل مرة
python3 raw-to-reel/server.py
```

تنفتح الصفحة تلقائياً على http://127.0.0.1:4680. ومن Claude Code تقدر تكتب `/raw-to-reel`.

## وش يسوي كل خيار

### ✂️ القص والمونتاج
| الخيار | الطريقة |
|---|---|
| قص الصمت | `silencedetect` من ffmpeg، ويترك 0.12 ث قبل الكلام وبعده |
| حذف الكلمات الزائدة | Whisper يعطي توقيت كل كلمة، وتنحذف «امم/اه/um/uh» |
| حذف الإعادات | إذا بدأت جملتين ورا بعض بنفس الكلمات، تنحذف الأولى وتبقى آخر محاولة |
| تتبّع الوجه | كاشف الوجه YuNet (OpenCV) يفحص لقطتين كل ثانية، والقص يلحق الوجه بحركة ناعمة ويرتّب نفسه عند تغيّر اللقطة |
| زوم تلقائي | تكبير 15% على لقطة وترك اللي بعدها |
| تقطيع لعدة ريلز | يقسّم الفيديو لريلز بالطول اللي تختاره (30–90 ث)، ويقص عند نهاية جملة |
| سرعة الكلام | ×1.1 أو ×1.2 للصورة والصوت مع بعض |
| المدة القصوى | يقص الفيديو من الآخر عند المدة المختارة |

### 💬 الترجمة والنصوص
| الخيار | الطريقة |
|---|---|
| ترجمة متحركة | كل 3 كلمات مع بعض، بخط Qatar2022، تختار اللون (7 ألوان) والحجم والمكان، ويطلع معها ملف SRT |
| المكان التلقائي | كل جملة تنحط في أقرب مكان ما يغطي الوجه ولا الجسم، وتثبت في مكانها لين يتحرك الشخص. والإنجليزي والـ Hook وعنوان الغلاف نفس الشي |
| تلوين الكلمة | الكلمة اللي تنقال تتلوّن بلون مختلف |
| ترجمة إنجليزية | Whisper يترجم الكلام للإنجليزي، ويطلع سطر تحت العربي + ملف SRT إنجليزي |
| Hook | نص كبير في أول 3 ثواني (تكتبه أو ياخذ أول جملة) |

### 🎨 الشكل والهوية
| الخيار | الطريقة |
|---|---|
| المقاس | 9:16 ريل، 4:5 بوست، 1:1 مربع، 16:9 يوتيوب |
| الشعار | ترفع صورة الشعار، وتطلع في الزاوية اللي تختارها |
| بطاقة نهاية | 3 ثواني بلون الترجمة: عنوان + رقمك أو حسابك + الشعار |
| صورة غلاف | يختار أوضح لقطة في أول 12 ثانية ويكتب عليها عنوان كبير |
| شريط تقدّم | خط رفيع فوق الفيديو يمتلي مع الوقت |
| تصحيح الألوان | تباين وتشبع خفيف |

### 🎵 الصوت
| الخيار | الطريقة |
|---|---|
| صوت استوديو | فلتر ضوضاء + كمبريسور + توحيد مستوى الصوت على ‎-14 LUFS |
| موسيقى خلفية | ترفع ملف صوت، ويوضع تحت صوتك على 12% |
| مؤثر ووش | صوت خفيف عند كل زوم وكل لقطة B-roll وقبل بطاقة النهاية |

### ✨ موشن على أهم الكلام
| الخيار | الطريقة |
|---|---|
| اختيار الكلمات | نقاط لكل كلمة: رقم (+4)، بعد «أهم/السر/انتبه/نصيحة…» (+2.5)، تتكرر (+2)، صوتك أعلى من العادي (+3)، كلمة كتبتها أنت (+10) |
| بطاقة الكلمة | الكلمة تنفجر على الشاشة بلون الترجمة مع خطوط حولها، والجملة تحتها، وتاخذ مكان الترجمة 1.7 ثانية |
| عدّاد الأرقام | «٥٠٪» تعد من صفر لين توصل للرقم |
| زوم سريع | دفعة زوم 8% على الوجه مع كل كلمة |
| صور | صورة من Pexels (تحتاج المفتاح) تنزلق على الشاشة مع حركة بطيئة، بالتناوب مع بطاقات الكلمات. كلمة البحث من الترجمة الإنجليزية |

### 🎞️ B-roll
| الخيار | الطريقة |
|---|---|
| B-roll من ملفاتك | صور (2.5 ث) أو مقاطع (لين 3.5 ث) تتوزع بالتساوي، بفاصل 8 ثواني على الأقل |
| B-roll من Pexels | يحتاج مفتاح مجاني من https://www.pexels.com/api ، يدوّر بكلمات تكتبها أو يطلّعها من الترجمة الإنجليزية |

## المخرجات (`raw-to-reel/workspace/jobs/<job>/`)
لفيديو واحد الأسماء تبدأ بـ `final`، ولعدة ريلز بـ `reel_1`، `reel_2`…
- `final.mp4`: الفيديو النهائي
- `final_thumb.jpg`: صورة الغلاف
- `final.srt` و `final_en.srt`: ملفات الترجمة
- `timeline.edl`: تستورده في Resolve من File › Import › Timeline
- `resolve_import.py`: يفتح مشروع جديد في Resolve ويبني الـ Timeline تلقائياً (لازم Resolve يكون مفتوح)

The face detector model in `models/` is YuNet from opencv_zoo (MIT, see `models/LICENSE-yunet`).
