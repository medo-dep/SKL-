# Raw to Reel ✳ — مونتاج الفيديو بضغطة واحدة

نسخة مجانية من الأداة اللي في الريل: صفحة تفتح في كروم، تختار الفيديو الخام، تفعّل التعديلات، وتضغط زر واحد، فتطلع لك ريل جاهز (1080×1920) مع Timeline لـ DaVinci Resolve.

## التشغيل

```bash
# مرة واحدة فقط
brew install ffmpeg            # ماك  (ويندوز: winget install ffmpeg)
pip install faster-whisper     # للترجمة وحذف الكلمات الزائدة والإعادات

# كل مرة
python3 raw-to-reel/server.py
```

تنفتح الصفحة تلقائياً على http://127.0.0.1:4680. ومن Claude Code تقدر تكتب `/raw-to-reel`.

## وش يسوي كل خيار

| الخيار | الطريقة |
|---|---|
| قص الصمت | `silencedetect` من ffmpeg، ويترك 0.12 ث قبل الكلام وبعده |
| حذف الكلمات الزائدة | Whisper يعطي توقيت كل كلمة، وتنحذف «امم/اه/um/uh» |
| حذف الإعادات | إذا بدأت جملتين ورا بعض بنفس الكلمات، تنحذف الأولى وتبقى آخر محاولة |
| ترجمة متحركة | كل 3 كلمات مع بعض، بخط Qatar2022 وخلفية برتقالية، وتنحرق على الفيديو، ويطلع معها ملف SRT |
| زوم تلقائي | تكبير 15% على لقطة وترك اللي بعدها |
| صوت استوديو | فلتر ضوضاء + كمبريسور + توحيد مستوى الصوت على ‎-14 LUFS |
| تصحيح الألوان | تباين وتشبع خفيف |
| موسيقى خلفية | ترفع ملف صوت، ويوضع تحت صوتك على 12% |
| Hook | نص كبير في أول 3 ثواني |

## المخرجات (`raw-to-reel/workspace/jobs/<job>/`)
- `final.mp4`: الفيديو النهائي
- `timeline.edl`: تستورده في Resolve من File › Import › Timeline
- `resolve_import.py`: يفتح مشروع جديد في Resolve ويبني الـ Timeline تلقائياً (لازم Resolve يكون مفتوح)
- `captions.srt`: ملف الترجمة

> B-roll والمؤثرات الصوتية بالذكاء الاصطناعي تحتاج خدمات AI مدفوعة، فما هي مضافة.
